```sh
HTTPS_PROXY=http://127.0.0.1:7897 NO_PROXY=localhost,127.0.0.1,::1 NODE_USE_ENV_PROXY=1 PORT=4186 npm start
```

`HTTPS_PROXY` 使用本机实际可用的 HTTP 代理地址。该启动配置只作用于服务进程，保存的模型地址、模型和密钥未修改。
